# Exoplanet KOI Classification — Code

Reproducible code for a machine-learning study of Kepler Objects of Interest
(KOIs) built entirely from public archive tables. The pipeline trains
gradient-boosted and probabilistic classifiers on two open input
representations of the same objects and reports, for each, accuracy, ranking
quality (AUC), calibration error, and predictive uncertainty. It also runs
feature-ablation, measurement-error, noise-sensitivity, and cross-mission
(Kepler to TESS) checks.

## Install

```
pip install -r requirements.txt
```

Pinned dependencies: numpy, pandas, scipy, scikit-learn, lightgbm, ngboost,
torch, matplotlib (see `requirements.txt`).

## Get the data

Inputs are public but downloaded separately. See `data/README.md` for the file
list and sources, then place the files in `data/` (or set `EXO_DATA_DIR`).

## Run

```
python reproduce.py        # regenerate every result file, then every figure
python reproduce.py --no-figs
python make_figures.py      # rebuild figures from saved results only
```

All randomness is fixed by the seeds in `src/config.py`, so every split is
regenerated deterministically. See `REPRODUCIBILITY.md` for the data-cleaning
and exclusion log, seed and split details, and a table/figure to script map.

## Layout

```
src/        analysis scripts (each writes one file into results/)
results/    saved metrics, out-of-fold and figure predictions
figures/    figures, all regenerated by make_figures.py
data/       download instructions for the public inputs
```
