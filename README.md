# Exoplanet KOI Classification — Code

Reproducible code for a machine-learning study of Kepler Objects of Interest
(KOIs) built entirely from public archive tables. The pipeline trains
gradient-boosted and probabilistic classifiers on two open input
representations of the same objects and reports, for each, accuracy, ranking
quality (AUC), calibration error, and predictive uncertainty. It also runs
feature-tier, measurement-error, noise-sensitivity, nested cross-validation,
and cross-mission (Kepler to TESS) checks, and compares against a recent
tabular baseline under the same protocol.

## Install

```
pip install -r requirements.txt
```

Pinned dependencies: numpy, pandas, scipy, scikit-learn, lightgbm, ngboost,
xgboost, torch, matplotlib. `pytabkit` is optional and needed only for the
recent-method comparison. Exact versions used for the released numbers are
recorded in `results/environment.json` together with the commit hash.

## Get the data

Inputs are public but downloaded separately. See `data/README.md` for the file
list and sources, then place the files in `data/` (or set `EXO_DATA_DIR`).

## Run

```
python reproduce.py                 # regenerate every result file, then every figure
python reproduce.py --no-figs       # analyses only
python reproduce.py --with-recent   # also the TabM comparison (needs pytabkit, GPU advised)
python make_figures.py              # rebuild figures from saved results only
python make_tables.py               # print the table values from saved results
```

All randomness is fixed by the seeds in `src/config.py`, so every split is
regenerated deterministically. The pipeline was executed twice from a clean
environment and the output files were byte-identical. See `REPRODUCIBILITY.md`
for the data-cleaning and exclusion log, seed and split details, and a
table/figure to script map.

## Layout

```
src/        analysis scripts (each writes one or more files into results/)
results/    saved metrics, out-of-fold predictions, per-candidate artifacts
figures/    figures, all regenerated by make_figures.py
data/       download instructions for the public inputs
```

## Determinism and environment

`results/environment.json` records the Python version, the exact version of
every library used to produce the released numbers, the GPU model where one
was used, and the commit hash. Library versions in `requirements.txt` are
pinned exactly rather than by lower bound, because several reported values
move at the third decimal place across minor versions.
