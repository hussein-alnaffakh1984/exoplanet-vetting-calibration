# Reproducibility Guide

This repository reproduces the tables and figures of the manuscript from public
input catalogues. Randomness is controlled by fixed seeds, including a fixed
seed inside the Bayesian network, so the pipeline is deterministic.

## 1. Environment

```
pip install -r requirements.txt
```

numpy>=1.24, pandas>=2.0, scipy>=1.10, scikit-learn>=1.3, lightgbm>=4.0,
ngboost>=0.5, xgboost>=2.0, torch>=2.0, matplotlib>=3.7.

## 2. Random seeds (deterministic)

Seeds are centralised in `src/config.py`:

- `SEEDS = [0, 1, 2]` — the three independent flux repeats.
- `random_state = 0` — every stratified train/calibration/test split, every
  five-fold cross-validation split, and the Kepler/TESS split.
- The Monte-Carlo-dropout Bayesian network sets `torch.manual_seed(0)` and
  `np.random.seed(0)` (in `src/flux_calibration.py`), so its training is
  deterministic.

Because the seeds are fixed, split membership is regenerated on every run; split
indices are therefore not stored as separate files.

## 3. Data cleaning and exclusion log

Inputs are public and downloaded separately (`data/README.md`). The
deterministic cleaning in `src/data.py` applies, in order:

1. **Label inclusion.** Only objects with a final `CONFIRMED` or
   `FALSE POSITIVE` disposition are kept; objects without a final disposition
   are excluded, as they carry no label.
2. **Missing values.** Remaining missing feature values are imputed with the
   median; records are not dropped for missing values (physical set: 0.6%
   missing before imputation).
3. **Natural class balance is retained** (no SMOTE / resampling).

| Representation | Cleaned n | Composition | Split |
| --- | --- | --- | --- |
| Flux (global view) | 5,302 | 41.4% CONFIRMED | stratified 70/15/15, x3 seeds (test n = 796) |
| Physical (7 params) | 6,695 | 2,730 CONFIRMED + 3,965 FALSE POSITIVE | stratified 5-fold CV, inner calibration split per fold |
| Cross-mission (TESS) | 2,125 | 6 shared features | Kepler-trained, TESS-tested |

`python src/data.py` prints the per-step inclusion/exclusion counts.

## 4. One-command reproduction

```
python reproduce.py        # run all analyses, then regenerate all figures
python make_figures.py      # rebuild figures from saved results only
```

## 6. Figures

Every figure is regenerated by `make_figures.py` from the saved result files,
so figure regeneration is exact:

`fig1_calibration` (flux_fig_preds.npz), `fig2_physical_model`
(phys_oof.npz, physical_model.json), `figS1_roc_confusion`,
`figS2_three_classifiers`, `figS4_measurement_terciles`, `figS5_cross_mission`,
`figS6_feature_leakage`, `figS7_noise_robustness`.

Calibration-bin and metric definitions (Brier, ECE, MC-dropout uncertainty) are
in `src/metrics.py`.

## 7. Numerical reproducibility note

The committed result files are the values reported in the manuscript.
Re-running the pipeline reproduces them as follows: the tree-based analyses
(LightGBM, NGBoost, XGBoost, the feature-ablation, and the Gaussian, correlated,
and Student-t noise models) reproduce the reported values exactly under the
fixed seeds and the pinned library versions. The seeded Bayesian network and the
remaining Monte-Carlo robustness variants reproduce the reported values within a
small numerical tolerance (of order 0.005), which is the expected variation
across hardware and library versions for stochastic neural-network training and
finite Monte-Carlo sampling. All scientific conclusions are unchanged within
this tolerance.

## 8. Trained models

All models are small and retrained end to end by `reproduce.py` in minutes on
CPU; trained-model binaries are not stored. Out-of-fold and figure-level
predictions are saved (`phys_oof.npz`, `flux_fig_preds.npz`).
